为什么信得住

不是相似度 · 是还原

反向推理成真实接口形态

不做字符串模糊匹配：数字、UUID、手机号等模式被识别为路径变量，`list` / `create` 这类固定路径不会被误吞进模板。

多目标 Host 隔离

每个应用一棵自己的树

一次喂入多个域名的流量，按 Host 分桶各自还原，不会跨目标相互污染，资产清单按主机聚合。

两层类型推断

从物理到逻辑语义

参数与变量既有 integer / string 物理类型，也有 uuid / phone / idcard 等逻辑类型，可直接导出 OpenAPI 3.0.3「黑盒版 Swagger」。
